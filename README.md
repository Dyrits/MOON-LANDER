# Moon Lander

A Java implementation of the classic Lunar Lander game, built for the CodeGym game task [Moon Lander](https://codegym.cc/projects/games/com.codegym.games.moonlander).

![Moon Lander](https://cdn.codegym.cc/images/system/013fcdf9-e770-42fb-a8b1-c2190cf1e97e/original.jpeg)

## About The Project

Pilot a lunar landing module and set it down gently on the Moon's surface without hitting the mountains. Use the main engine to slow the descent and gain a little altitude, and the side engines for horizontal movement. The softer and more even the landing, the more points you get.

From the author's notes: this project was made from scratch following the task's specific instructions, with several elements (such as the game engine) provided by the course.
